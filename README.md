# semana-04
Projeto desenvolvido para praticar conceitos básicos de Python, utilizando listas, dicionários, conjuntos, laços de repetição e f-strings.

cadastrodeprodutos.py — Cadastra produtos com nome, preço e categoria.
conjuntodecategorias.py — Identifica e exibe as categorias sem repetições.
filtragemdopreço.py — Separa os produtos de acordo com um preço limite.
ordenação crescente.py — Organiza os produtos por preço em ordem crescente e decrescente.
tulhadeestatísticas.py — Calcula o menor preço, o maior preço e a média dos valores cadastrados.
relatoriofinal.py — Exibe o relatório com os produtos, as categorias e as estatísticas.
portugol.py — Demonstra a lógica de ordenação pelo método Bubble Sort, identificação manual de categorias únicas e cálculo de estatísticas.

Objetivo:
Praticar a lógica de programação e aprender a manipular, organizar, filtrar e analisar dados utilizando Python.
